## 1. 软件说明

微屏是一个 Windows 桌面侧边栏程序。运行后会在屏幕左右两侧各停靠一条窄面板，面板里可以放便签、待办、计时器、日历、文件快捷方式等小模块，程序启动后自动在后台常驻。

主要用途是把平时需要切换窗口才能看到的东西放到屏幕边上，减少来回切换。不登录也可以使用大部分本地功能，登录后可使用云同步和团队共享。

软件由以下几部分组成，日常使用只涉及第 1 项：

| 组成 | 说明 |
|---|---|
| 微屏客户端 | Windows 桌面程序，本手册的介绍对象 |
| 元素拾取器扩展 | Chrome 浏览器扩展，配合"数据看板"模块使用 |
| 网站管理台 | 供运营和企业管理员使用，普通用户无需接触 |
| 服务端 | 由软件方部署，用户不需要安装 |

## 2. 安装与启动

### 2.1 环境要求

- Windows 10（19041 及以上）或 Windows 11，64 位
- 屏幕分辨率建议 1920×1080 以上；分辨率较低时建议把侧边栏宽度调小或使用"浮动"模式
- 需要联网才能使用登录、云同步、数据看板抓取、插件市场等功能

### 2.2 安装

1. 从官网下载安装包（中文区 `sidedesk.bigjing.com`，国际区 `sidedesk.desktxp.com`）。
2. 双击安装包，按提示完成安装。
3. 安装完成后桌面会出现"微屏"快捷方式，任务栏右下角托盘区也会出现图标。

### 2.3 启动与退出

- 启动：双击快捷方式，或从开始菜单打开。启动后侧边栏会直接出现在屏幕两侧。
- 默认勾选了"开机自动启动"，可在 [设置 → 常规](#61-常规) 中关闭。
- 退出：点击侧边栏右上角的 `…` → 底部菜单中的「退出」。仅关闭窗口不等于退出程序。

### 2.4 更新

程序会定期检查新版本并自动完成更新，更新期间不需要手动干预。如需立即检查，可在「设置 → 工具」中手动触发。

## 3. 界面构成

![侧边栏整体](.smoke/FINAL_sidebar_overview.png)

一条侧边栏从上到下分三部分：

| 区域 | 内容 |
|---|---|
| 标题栏 | 左侧显示序号和"微屏"名称，右侧是 `…` 主菜单按钮 |
| 模块区 | 中间的可滚动区域，每个小功能是一个"模块"，模块有自己的标题栏 |
| 状态栏 | 底部一行，显示少量实时数字（键鼠计数、内存等），右侧是「AI 助手」入口 |

其他界面元素：

- **模块标题栏**：显示模块图标和名称，右侧有一个 `▾` 按钮，点击后弹出该模块的菜单（与在模块上点右键效果相同）。
- **左右两条栏**：可以只开一侧，也可以两侧都开，两侧内容互不影响。
- **多窗口**：一条侧边栏称为一个"微屏"，可以创建多个微屏，通过主菜单顶部的编号项（如 `1. 主页`、`2. 新窗口`）切换。
- **浮动图标列**：鼠标移到屏幕边缘时，可能出现一列竖排小图标，用于快速打开常用窗口。

主菜单内容如下：

![主菜单与添加模块](.smoke/X_01_addmenu_components.png)

| 菜单项 | 作用 |
|---|---|
| 1. 主页 / 2. 新窗口 … | 切换当前微屏 |
| 创建微屏 | 新建一个微屏窗口 |
| 导入分享 | 输入共享码，把别人分享的模块添加进来 |
| 添加模块 | 展开可添加的模块列表 |
| 微屏管理 | 管理已创建的微屏 |
| 通知中心 | 查看历史通知 |
| 设置 | 打开设置窗口 |
| 工具 | 内置小工具 |
| 关闭面板 | 隐藏当前侧边栏 |
| 用户名 / 退出 | 显示当前登录用户；退出程序 |

## 4. 基本操作

### 4.1 添加模块

`…` → 「添加模块」→ 点击要添加的模块名，模块会出现在当前侧边栏的末尾。

可添加的模块：分组、快捷方式、便签、今日待办、剪贴板收藏、系统信息、屏幕时长、文件区、数据看板、计时器、倒计时、番茄闹钟、信号灯、打卡、图片轮播、每日活跃、日历、好友、百度搜索，另有「添加数据块」「插件」两个子菜单和「从团队组件库添加…」。

### 4.2 模块通用菜单

在模块上点右键，或点模块标题栏右侧的 `▾`：

![模块菜单示例](.smoke/D_D02_dashboard_compmenu.png)

| 菜单项 | 说明 |
|---|---|
| 模块设置 | 打开该模块的设置对话框（各模块内容不同） |
| 分享模块 | 把该模块分享给他人或团队 |
| 布局 / 列 / 样式 / 视图 | 调整该模块的显示形式，部分模块才有 |
| 隐藏模块外框 | 去掉边框和标题，让内容直接贴在桌面上 |
| 置顶显示 | 把该模块固定在滚动区上方，不随内容滚走 |
| 删除模块 | 删除该模块 |

模块的显示顺序可以通过拖动调整。

### 4.3 调整宽度和位置

`…` → 「设置」→「常规」，可以设置停靠在哪一侧（左侧 / 右侧 / 两侧 / 不显示）以及左右两侧各自的宽度（5~500 像素）。

"开启浮动"打开后，侧边栏平时收在屏幕边缘，鼠标移过去才展开，适合屏幕较小的情况。

### 4.4 隐藏与显示

- 主菜单中的「关闭面板」可临时隐藏。
- 程序提供全局快捷键用于显示/隐藏侧边栏，具体按键和修改方式见「设置 → 工具」。

## 5. 模块使用说明

### 5.1 便签

模块内会列出已有便签，点击某条便签会弹出独立的便签窗口，窗口内直接编辑文字。

![便签窗口](.smoke/X_07c_theme_light_full.png)

- 窗口底部有「保存」和「复制全文」两个按钮。
- 也可以不点保存，编辑完直接关闭窗口，内容会保留。
- 新建便签：模块菜单 →「模块设置」，或在模块空白处按提示新建。
- 便签分两类：模块内便签（跟随该模块）和全局便签（在任意位置都能列出）。

### 5.2 今日待办

在模块底部的输入框里写内容，回车即新增一条；点条目左侧的方框标记完成。

![待办模块](.smoke/X_99_final_left.png)

- 待办按当天有效，第二天会归档，不会一直堆积。
- 条目可以拖动排序。

### 5.3 快捷方式

用于把常用的文件、文件夹、网址放到侧边栏。

![新建快捷组](.smoke/C04b_shortcut_dialog.png)

- 先新建一个"快捷组"并命名，之后可以建多个组分别存放。
- 添加方式：组内 `▾` 菜单中选择添加文件 / 文件夹 / 网址 / 云文件，也可以直接把文件拖到组上。
- 网址类条目会自动取网站图标。
- 双击条目即打开对应项目。

### 5.4 文件区

与快捷方式类似，但以大图标 / 小图标 / 列表方式显示文件夹内容，支持拖放。

![文件区菜单](.smoke/M_A03_filearea_layout.png)

- 菜单中可切换布局（大图标、小图标、列表、弹出显示）和列数（1~4 列）。
- 「添加文件」「添加文件夹」「添加云文件」分别对应本地文件、本地文件夹和云端文件。

### 5.5 剪贴板收藏

保存需要长期留下的剪贴板内容（文字、图片、文件路径）。

![收藏剪贴板内容](.smoke/C03d_clipboard_dialog.png)

- 复制内容后，在模块菜单中选择"收藏"，会列出最近复制过的内容，勾选后点「添加」。
- 收藏后的条目永久保留，点击即可重新复制到剪贴板。
- 另有一个"剪贴板历史"模块，用于查看最近自动记录的内容（约 100 条），不长期保存。

### 5.6 计时器 / 倒计时

- **计时器**：正向累计计时，标题栏的圆形按钮开始/暂停，可添加多个并同时运行。
- **倒计时**：设定一个目标时间点，模块显示剩余时间，模块内没有条目时提示"暂无倒计时"。

### 5.7 番茄闹钟

![番茄钟模块](.smoke/X_99_final_left.png)

- 顶部下拉框选择模式：番茄钟 / 短休息 / 长休息。
- 中间圆环显示剩余时间，下方按钮开始或暂停。
- 底部显示本轮已完成的番茄数。
- 默认时长可在「模块设置」中修改。

### 5.8 打卡

用于记录"今天喝了几次水"这类计数。

![添加打卡](.smoke/T_D10_picker_dialog.png)

- 模块设置对话框上半部分是常用打卡（喝水、起身活动、护眼远眺、吃药、深呼吸、散步），点一下即加入；「自定义打卡」可以自己填文字、选图标和颜色。
- 下半部分是已添加的打卡列表，可逐条编辑或删除。
- 使用时点一下按钮，右上角的数字加一。
- 模块菜单中可改「列数」（1~4 列）和「样式」（仅文字、仅图标、图标文字竖置、图标文字横置）。

![打卡四列显示](.smoke/T_D05_4col.png)

![仅图标样式](.smoke/T_D08_style2.png)

### 5.9 信号灯

显示几个彩色圆点，用来标记状态。

![设置信号灯](.smoke/M_C04_signallight_dialog_full.png)

- 可设置排列方向（横向 / 纵向）、灯样式、灯大小、间距、对齐方式。
- 每个灯可单独设置颜色和大小，可增删。
- 灯的状态可以通过外部程序改变，具体方式请另行索取接口说明。

### 5.10 数据看板

把网页上的某个数字或文字显示在侧边栏里，按设定时间自动刷新。

![添加数据项](.smoke/D_D06_dialog_combos.png)

操作步骤：

1. 在数据看板模块菜单中选「添加数据项」。
2. 填"数据项名称"，例如 `bing天气`。
3. 选择获取方式（页面选择器）。
4. 填目标网页地址。
5. 选择选择器类型（XPath / CSS 等）并填选择器内容——这一项建议用浏览器扩展拾取，见 [第 9 章](#9-浏览器扩展元素拾取器)。
6. 填刷新间隔，默认 60 秒。
7. 选择所属团队（个人 / 某个团队）。
8. 填变量名，作用域内不能重复。
9. 选择浏览器和浏览器 Profile；如果没有打开浏览器，程序会自行使用一个后台浏览器读取页面。
10. 点「确定」。

对话框顶部还有另外三个页签：

- **数据模板**：从已有模板中选一个，只需再填网址等少量信息。

  ![数据模板页签](.smoke/D_D07_dialog_tab_数据模板.png)

- **数据模板市场**：浏览和导入别人做好的模板。
- **我的数据看板**：管理自己已建的数据项。

模块菜单中的「布局」可设置显示为 1~4 列。

**关于变量**：每个数据项对应一个"变量"，变量名就是这条数据的标识。同一个变量在多台设备上会保持一致；多个数据项也可以用一个"变量集"按求和、平均、最大、最小、计数汇总成一条显示。

### 5.11 系统信息

显示 CPU、内存、网络等本机指标，无需配置。

### 5.12 屏幕时长 / 使用统计 / 每日活跃

- **屏幕时长**：需要先开启「使用时长统计」，开启后开始记录，未开启时模块显示"暂无数据"。模块菜单中有样式选项。
- **使用统计**：按应用统计前台使用时间。
- **每日活跃**：以点阵方式显示每天各项记录的次数。

  ![每日活跃菜单](.smoke/D_C04_dailyactivity_submenu.png)

  模块菜单中可切换「视图」（今日 / 本周 / 本月）和「数据类型」，也可以手动刷新。打卡模块的计数会同时汇总到这里。

### 5.13 日历

显示当前日期和月历，无配置项。

### 5.14 图片轮播

在指定目录里循环显示图片。首次使用时模块会提示未设置目录，通过标题栏 `▾` → 设置选择目录即可。

### 5.15 百度搜索

在侧边栏内嵌一个网页窗口，可以直接搜索和浏览。类似的内嵌网页模块还可以放其他常用站点。

### 5.16 好友

显示好友列表和在线状态（如"离线"）。好友关系在管理台或客户端添加，添加后双方可以看到对方共享出来的便签、数据项等内容。

### 5.17 分组

把若干模块放进一个组里，可以折叠收起，也可以给组设置背景色。

### 5.18 数字员工

登录后显示可用的数字员工列表，数量由服务端配置。模块菜单中可设置每排显示几个（1~5 个）。

### 5.19 插件

「添加模块 → 插件」下列出已安装的插件模块。

![插件子菜单](.smoke/X_05_plugin_submenu.png)

- 安装插件：「设置 → 插件」页面中从插件市场安装，或选择本地插件包导入。
- 内置插件目前有"问候组件""系统清理"等。
- 插件的编写方式请另行索取插件说明文档。

### 5.20 AI 助手

侧边栏底部状态栏右侧的「AI 助手」入口，打开后可以输入或说出一句话，由它代为完成建便签、查待办、切主题、控制番茄钟等操作。

- 使用需要登录并配置可用的模型密钥（「设置 → 工具」或账户页面中配置）。
- 该功能为辅助性质，涉及删除的操作会先要求确认。

## 7. 账户与云同步

### 7.1 登录

`…` → 用户名一栏上方区域，或「设置 → 账户」中登录。支持浏览器授权登录和手机号验证码登录。未登录时，本地模块可以正常使用，但无法同步和共享。

### 7.2 云同步

![设置-账户](.smoke/X_09a_account.png)

- 「云同步」开关：开启后每 30 分钟自动把本地配置备份到服务器，退出程序时再同步一次。
- 「立即同步」：手动触发一次同步。
- 「加密同步」：开启后备份内容在上传前加密。
- 页面会显示上次同步时间。换电脑或在公司/家里两台电脑之间，登录后同步即可拿到同样的模块和配置。

同步的内容包括微屏结构、模块配置和模块数据。个别只在本地有意义的内容（例如某些临时记录）不参与同步。

## 8. 团队与分享

### 8.1 分享模块

在模块菜单中选「分享模块」，选择共享给某个人还是某个团队，以及对方是否可以操作（只读或可写），确定后生成共享码。

### 8.2 接收分享

对方在 `…` → 「导入分享」中输入共享码即可添加。添加进来的模块外框会带颜色标识（颜色在「设置 → 外观」中改）。

一个人可以同时在多个团队里，不需要切换团队——不同团队共享过来的模块可以混放在同一个微屏中。

### 8.3 团队组件库

`…` → 「添加模块」→ 「从团队组件库添加…」，选择团队后列出该团队已共享的模块，添加后数据与团队互通。

![团队组件库](.smoke/X_10_teamlibrary_dialog.png)

如果列表为空，说明该团队还没有人共享模块，需要在自己模块的设置里把归属改为团队。

### 8.4 成员操作提醒

团队成员改动共享的卡片或微屏时，其他成员会在通知条和通知中心收到一条提示，说明谁做了什么。为避免刷屏，只有内容确实发生变化时才会提醒；数据看板抓取到的数值变化不算成员操作，不会提醒。

## 9. 浏览器扩展（元素拾取器）

配合数据看板使用，用来在网页上点一下就能取到该元素的选择器。

### 9.1 安装

1. 地址栏输入 `chrome://extensions/`。
2. 打开右上角"开发者模式"。
3. 点"加载已解压的扩展程序"，选择扩展文件夹。

### 9.2 使用

1. 打开要取数据的网页，并登录到能看到数据的状态。
2. 点击浏览器工具栏中的扩展图标。
3. 点"开始选择"，按钮变绿表示已进入选择状态。
4. 移动鼠标，目标元素会有蓝色高亮框，点击该元素。
5. 选择器会显示在扩展面板的文本框中，点"复制"。
6. 回到微屏的数据项设置里粘贴到"选择器内容"。
7. 按 `ESC` 可退出选择状态。

### 9.3 选项

| 选项 | 作用 |
|---|---|
| 优先使用 ID | 元素有 id 属性时优先用 `#id` |
| 使用 Class | 选择器中包含 class 名 |
| 显示标签名 | 选择器中保留 div、span 等标签名 |
| 自动处理重复元素 | 同级同类元素较多时补 `:nth-child` |

### 9.4 注意

- 动态生成的页面元素，选择器可能在改版后失效，建议优先选有唯一 id 的元素。
- 设置完成后可以关掉那个网页，微屏会自行在后台读取。
- 需要登录才能看到的页面，请在已登录的浏览器和 Profile 中选择，并在数据项里指定同一个浏览器和 Profile。

## 10. 常见问题

**侧边栏挡住了下面的窗口**
在「设置 → 常规」里把停靠位置改为单侧或"不显示"，或减小宽度、开启浮动模式。

**看不到某个模块**
模块可能被滚动到下面了，也可能被折叠进了分组；也可以在「微屏管理」里确认当前微屏是否包含该模块。

**数据看板一直不更新**
依次检查：目标网址是否能正常打开、账号是否仍处于登录状态、选择器是否指向了会变化的元素、刷新间隔是否设置过大。改版或失效时重新用扩展拾取一次选择器。

**换了电脑后配置不对**
确认两台电脑登录的是同一账号，并且「设置 → 账户」中云同步已开启，然后点一次"立即同步"。

**同步后本地内容被覆盖**
云同步以服务器上的记录为准。多台设备同时改动同一模块时，建议先在一台设备上同步完成，再在另一台设备上同步。

**通知太多**
「设置 → 外观」中关闭"显示通知条"，或在通知中心里清空。团队操作提醒只在内容确实变化时才发。

**程序没有随 Windows 启动**
检查「设置 → 常规」中的开机自启是否开启；部分安全软件会阻止开机启动项，需要在安全软件中放行。

**侧边栏文字或图标显示不全**
一般是宽度过小或系统缩放比例过高所致，把宽度调大一些即可。

**卸载**
在 Windows「应用和功能」中卸载。卸载前如需保留数据，请先执行一次立即同步。本地数据目录在卸载时可以选择是否删除。
