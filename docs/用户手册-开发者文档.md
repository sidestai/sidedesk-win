# SideDesk 开发者文档

## 多语言（i18n）开发约定

### 基本原则

- **所有新增的用户可见文案必须走多语言机制**，禁止在代码或 XAML 中硬编码中文/英文等用户可见文本：
  - C# 代码：`Lang.T("键")` / `Lang.TF("键", args)`（带占位符 `{0}` `{1}` …）
  - XAML：`{l:T 键}` 标记扩展（需 `xmlns:l="clr-namespace:SideDesk.Framework"`），切换语言时已注册目标实时刷新
- 日志输出、协议层固定文本（如 HTTP header、错误码常量）不属于用户可见文案，无需接入。
- **用户数据默认值与数据值文本不接入翻译**：如模型默认名、分类名、作为匹配标识的固定名称、品牌名等。这类文本参与持久化存储与匹配逻辑，翻译会破坏存量数据与匹配行为；如需多语言呈现，在展示层用 `Lang.T` 转换（参考 `AIChatDialog.GetModelDisplayName` 对“自定义”模型名的处理），数据值本身保持原样。

### 键命名规范

- 格式：`{域}.{区域}.{语义}`，小写驼峰，点分层，**最多 4 层**。
  - 示例：`settings.apiKey.deleteConfirm`、`common.accept`、`market.pluginInstallFailed`
- 域对应功能模块（如 `common`、`settings`、`market`、`nativePanel`、`window`、`login`、`data` 等），语义部分用简短英文描述文案含义，**不使用拼音或中文**。

### 词典与键表文件

- `tools/i18n/keymap.json`：中文键 → 语义键的总映射表（1510 中文键 / 1503 语义键）。
- `langs/{语言代码}.json`：13 种语言词典（zh-CN / en / de / es / fr / it / ja / ko / pl / pt-BR / ru / tr / zh-TW），运行时由 `Framework/Lang.cs` 加载，改翻译无需重新编译。
- `langs/_legacy.json`：中文旧键 → 语义键的运行时归一化兼容层。**永久保留**：项目存在插件市场机制，外部插件可能仍调用 `Lang.T("中文")`，保留后仅多一次字典查询，成本可忽略。
- `tools/i18n/translations-override.json`：非英语言补译覆盖文件，结构 `{ "语言": { "语义键": "译文" } }`，由 `gen-dicts.ps1` 在词典生成后应用，保证幂等可复现。

### 新增键流程

1. 在 `tools/i18n/keymap.json` 增加 `中文键 → 语义键` 映射（中文键即文案原文，便于存量兼容）；
2. 运行 `powershell -ExecutionPolicy Bypass -File tools\i18n\gen-dicts.ps1`：
   - 从 `tools/i18n/sources/` 快照幂等重建 `langs/` 全部词典；
   - 新键在非英语言中以英文占位，并自动登记到 `tools/i18n/pending-translations.md` 待译清单；
3. 翻译补写：把译文写入 `tools/i18n/translations-override.json` 对应语言，重跑 `gen-dicts.ps1`（待译清单自动扣除已覆盖键）；
4. **提交前运行** `powershell -ExecutionPolicy Bypass -File tools\i18n\check-i18n.ps1` 校验：
   - 语义键唯一性与 13 词典键集一致；
   - 译文占位符 `{n}` 与源文案一致；
   - 代码调用点 ↔ 词典双向孤儿检查；
   - 硬编码中文扫描（已知豁免：`SettingsWindow.xaml` 语言下拉 2 处、`Framework/Lang.cs` 类注释 1 处、日志/协议层文本、用户数据默认值与数据值文本）。

### 翻译回退链（fallback）

`Lang.T` 查询顺序：当前语言词典 → en 词典（懒加载缓存）→ 键本身；
中文旧键在入口经 `_legacy.json` 归一化为语义键后同轨查询。
最终回落为键本身且当前语言非 en 时，记入缺键集合，退出时追加写入 `%LocalAppData%\SideDesk\Logs\lang-missing.log`。

### 已知限制

- 语言切换后，**命令式赋值**的文本（如 `textBlock.Text = Lang.T(...)` 一次性赋值）与 **Style/Template 内 Setter** 绑定的文本无法实时刷新，需重开窗口/重建控件后生效；`{l:T}` 直接绑定与 `Lang.Register` 注册的目标可实时刷新。
- 词典文件在 `Init`/`Apply` 时加载，运行中修改翻译需触发一次 `Apply`（同语言重载）或重启应用。
